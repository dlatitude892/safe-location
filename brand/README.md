# Safe Location brand files

The logo is the **Circle of trust**: you in the centre, with your trusted people on a ring around you. The ring is
broken where each person sits, because each of them is a real person you chose, not a closed system.

| File | Use it for |
|---|---|
| `logo-tile.svg` | The main logo: white mark on a violet rounded tile. Website header, browser tab, documents. |
| `logo-mark-white.svg` | The mark alone, white, for dark or violet backgrounds. |
| `logo-mark-violet.svg` | The mark alone, violet, for white or light backgrounds. |
| `app-icon.svg` | Square, full-bleed app icon master (the phone rounds the corners itself). |
| `app-icon-1024.png` | App Store and Google Play listing icon. |
| `icon-512.png`, `icon-192.png` | Android launcher and installable web app (manifest) icons. |
| `apple-touch-icon-180.png` | iPhone home screen icon for the website. |
| `favicon-32.png`, `favicon-16.png` | Browser tab icons for old browsers (the pages already use an inline SVG icon). |
| `social-1200x630.png` | Link preview image for WhatsApp, X, Facebook and LinkedIn. |

**Colours:** violet `#7c3aed` tile, white `#ffffff` mark. **Don't** stretch the logo, change the mark's colours,
add effects to it, or put the white mark on a light background.
